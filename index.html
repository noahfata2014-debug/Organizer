Features

Simple by default, flexible when needed.

◆ Smart folder routing

Files go into six folders based on type: Images, Documents, Media, Code, Archives, and Installers.

◆ Custom rules

Route files by name, like sending anything with “Invoice” to an Invoices folder.

◆ Date folders

Group files by month, such as Documents / 2026-November.

◆ Overwrite protection

Files with the same name get a counter, like image (1).png. Nothing is replaced.

Privacy

Private by design.

File Organizer uses your browser’s File System Access API to read and move files directly on your machine. Nothing is uploaded. It edits real folders, so it needs Chrome, Edge, or Opera on a computer. Safari and Firefox aren’t supported.

FAQ

Quick answers before you start.

Are my files uploaded anywhere?

No. Sorting runs in your browser, and files are read and moved on your own device.

Can I undo a sort?

Yes. Right after sorting, press Undo to move every file back.

Does it sort files inside subfolders?

No. It only sorts the files directly inside the folder you choose.
